# 출결 알림 (안드로이드)

담임용 출결 알림 앱. 데이터(명단·출결 기록)는 폰 안에만 저장됩니다.

## 기능
- **조회**: 없는 학생을 누르면 빨강 표시 → 설정한 시각(기본 08:50, 09:00, 12:30)에 아직 출석 확인이 안 된 학생이 있으면 알림. 모두 출석 체크(또는 결석 입력)되면 알림 없음.
- **출결 입력**: 학생을 길게 누르거나 '사유' → 결석·지각·조퇴·결과 × 인정·질병·미인정·기타, 메모.
- **서류 안내**: 서류가 필요한 기록(모든 결석, 인정지각, 모든 조퇴·결과)을 입력한 날의 다음 등교일 08:35(설정 가능)에 출결서류 안내·제출 알림. 주말·설정한 휴일/방학은 건너뜀. '서류 제출' 체크 시 미제출 목록에서 빠짐.
- **날짜별 기록**: 날짜를 넘기거나 눌러서 다른 날 기록 조회·입력.
- **통계·PDF**: 기간별 학생별 집계, 서류 미제출 목록, PDF 저장(다운로드/출결알림 폴더).
- **자동 업데이트**: 앱을 열 때 GitHub 최신 릴리스를 확인해 설치 화면까지 열어줌.

## 빌드
`main`에 푸시하면 GitHub Actions가 서명된 APK를 빌드해 Releases에 `v{빌드번호}`로 올립니다.

저장소 Settings → Secrets and variables → Actions에 아래 4개가 필요합니다.

| 이름 | 내용 |
|---|---|
| `KEYSTORE_BASE64` | 서명 키(jks)를 base64로 인코딩한 값 |
| `KEYSTORE_PASSWORD` | 키스토어 비밀번호 |
| `KEY_ALIAS` | 키 별칭 |
| `KEY_PASSWORD` | 키 비밀번호 |

서명 키가 바뀌면 기존 앱 위에 업데이트 설치가 되지 않으니 키를 바꾸지 마세요.

## 폰 설정
1. Releases에서 `attendance-alert.apk`를 받아 설치 (출처를 알 수 없는 앱 허용)
2. 알림 권한 허용
3. 설정 → 배터리 → 이 앱 '제한 없음'
4. 앱 설정에서 학급 명단·휴일 입력
